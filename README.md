# CAPTCHA VLM Evaluation

This repository contains the Python code used for a semester research project evaluating GPT-4o on various CAPTCHA tasks.

## Project Overview

The objective of this project is to evaluate the performance of a Vision-Language Model (GPT-4o) on different CAPTCHA categories using task-specific prompting and quantitative evaluation metrics.

## CAPTCHA Categories

- OCR
- Object Selection
- Coordinate Localization
- Arithmetic
- Common Sense Reasoning
- Rule-based Filtering

## Technologies

- Python
- OpenAI GPT-4o API
- Pandas

## Notes

The original CAPTCHA datasets are not included in this repository due to research and licensing considerations.
